# Jo Shinonome

I work as a data engineer and quant developer.

I'm interested in solving low-latency problems, improving performance, and designing user-friendly APIs.

I greatly enjoy using `Rust`.

## Open Source Projects

- [kola](https://github.com/jshinonome/kola), a `Polars` interface to `q` in `Rust`/`Python`
- [chili-neovim](https://github.com/jshinonome/chili-neovim), a `Neovim` plugin for `chili` and `q`
- [chilin](https://github.com/jshinonome/chilin), a `JavaScript` Node.js package to interface with chili
- [kuki](https://github.com/jshinonome/kuki), a `q` package manager
- [jkdb](https://github.com/jshinonome/jkdb), a `JavaScript` interface to `q`
